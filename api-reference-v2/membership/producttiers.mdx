## Authorization

<ResponseField name="Authorization" type="string" required>
  Example:

  `Authorization | Bearer Paste-Your-API-Key-Here`
</ResponseField>

## Path Parameters

<ParamField path="productId" type="string" required>
  The unique identifier of the membership product whose tiers you want to list. Only
  tiers with status `ACTIVE` for this product are returned.

  Example:

  `7c9d2e1f-4a5b-4c6d-8e9f-0a1b2c3d4e5f`
</ParamField>

## Query Parameters

<ParamField query="page" path="page" default="1" type="integer">
  The page number to retrieve, starting at `1`. Defaults to `1`.
</ParamField>

<ParamField query="pageSize" path="pageSize" default="10" type="integer">
  Number of tiers to return per page. Defaults to `10`.
</ParamField>

<Warning>
  Unlike **Get Membership Tiers** (`GET /hl/v2/memberships/tiers`), this endpoint uses
  page-based pagination. Paginate with `page` / `pageSize` and read `pageCount` / `total`
  from the response — there is no `startingAfter` cursor here.
</Warning>
