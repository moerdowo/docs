## Request Body

<ParamField path="amount" type="integer" required>
  Nominal amount of payment. Must be a positive integer of at least `500`. This is
  the only required body field.
</ParamField>

<ParamField path="name" type="string">
  Customer/payer name. When an `email` is supplied, this is used as the name of the
  customer record created for the payer. (The payment request's own internal title
  is set by the API.)
</ParamField>

<ParamField path="email" type="string">
  Customer email used to send proof of payment or payment reminders. When present,
  a customer record and a transaction are created and a `transactionId` is returned.
</ParamField>

<ParamField path="mobile" type="string">
  Customer telephone number.
</ParamField>

<ParamField path="description" type="string">
  General description of the transaction or order.
</ParamField>

<ParamField path="redirectUrl" type="string">
  URL to redirect the customer to after a successful payment.
</ParamField>

<ParamField path="notes" type="string">
  Additional notes for the payment request.
</ParamField>

<ParamField path="expiredAt" type="string (format ISO 8601 date-time)">
  The transaction expiration date and time. After this time, the payment link is
  no longer valid.
</ParamField>

<ParamField path="paymentMethod" type="string">
  Restrict the payment request to a specific payment method.
</ParamField>

<ParamField path="cashtag" type="string">
  Cashtag associated with the payment request.
</ParamField>

<ParamField path="extraData" type="object">
  Additional custom data attached to the payment request.
</ParamField>

## Response

Successful Response

### Main Structure (Root)

<ResponseField name="statusCode" type="integer" >
  Status code form API.
</ResponseField>

<ResponseField name="messages" type="string" >
  Status message that describes the status code.
</ResponseField>

<ResponseField name="data" type="object">
  The created payment request data.
</ResponseField>

### data Structure (Object)

<ResponseField name="id" type="string<uuid>" >
  Unique request payment ID.
</ResponseField>

<ResponseField name="transactionId" type="string<uuid> | null" >
  Unique transaction ID associated with this payment request. `null` unless an
  `email` was provided at creation (which also creates the customer transaction).
</ResponseField>

<ResponseField name="paymentLinkId" type="string<uuid>" >
  Payment link ID backing this payment request (equal to `id`).
</ResponseField>

<ResponseField name="link" type="string" >
  The URL that customers can access to open the payment request.
</ResponseField>

<ResponseField name="amount" type="integer" >
  The nominal amount of the payment request.
</ResponseField>

<ResponseField name="description" type="string | null" >
  Payment request description (HTML tags are stripped).
</ResponseField>

<ResponseField name="notes" type="string | null" >
  Additional notes attached to the payment request.
</ResponseField>

<ResponseField name="status" type="string" >
  Payment request status. `unpaid` for a freshly created request.
</ResponseField>

<ResponseField name="expiredAt" type="string (ISO 8601) | null" >
  Expiration date-time as an ISO 8601 string. Defaults to one hour after creation
  when not supplied.
</ResponseField>

<ResponseField name="createdAt" type="string (ISO 8601)" >
  Creation date-time as an ISO 8601 string.
</ResponseField>

### Errors

<ResponseField name="400 Bad Request" type="object">
  Returned when the request body fails validation:
  `{ "statusCode": 400, "messages": "Validation Error" }`.
</ResponseField>

<ResponseField name="409 Conflict" type="object">
  Returned when a payment request with the same identifier already exists:
  `{ "statusCode": 409, "messages": "already exist" }`.
</ResponseField>

<ResponseField name="429 Too Many Requests" type="object">
  Returned when a duplicate create request is detected:
  `{ "statusCode": 429, "messages": "Duplicate request detected. Please wait 1 minute before trying again." }`.
</ResponseField>
