## Authorization

<ResponseField name="Authorization" type="string" required>
  Example:

  `Authorization | Bearer Paste-Your-API-Key-Here`
</ResponseField>

## Path Parameters

<ParamField path="customerId" type="string" required>
  The unique identifier of the customer whose credit history is being queried.
</ParamField>

## Query Parameters

<ParamField query="productId" type="string">
  The unique identifier of the product associated with the credit history.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Number of items to return per page. Defaults to `10`.
</ParamField>

<ParamField query="sortField" type="string" default="datetime">
  Field to sort the results by. Defaults to `datetime`.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort direction, either `asc` or `desc`. Defaults to `desc`.
</ParamField>

<ParamField query="startDate" type="string">
  Filter results from this date (inclusive).
</ParamField>

<ParamField query="endDate" type="string">
  Filter results up to this date (inclusive).
</ParamField>

<ParamField query="walletType" type="string">
  Filter results by wallet type (e.g. `MAIN`, `ADD_ON`).
</ParamField>

<ParamField query="type" type="string">
  Filter results by transaction type (e.g. `MERCHANT_TOPUP`).
</ParamField>

Successful Response

<ResponseField name="statusCode" type="integer">
  Status code from API.

<ResponseField name="total" type="integer">
  Total number of history records matching the query.
