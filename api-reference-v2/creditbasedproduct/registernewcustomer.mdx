## Request Body

<ParamField body="productId" type="string" required>
  The unique identifier of the product to register the customer on.
</ParamField>

<ParamField body="trialCredit" type="number">
  The trial credit amount to grant upon registration.
</ParamField>

<ParamField body="customerInfo" type="object" required>
  Object containing the new customer's details.
</ParamField>

### customerInfo Structure (Object)

<ParamField body="customerInfo.name" type="string" required>
  Full name of the customer.
</ParamField>

<ParamField body="customerInfo.email" type="string" required>
  Email address of the customer.
</ParamField>

<ParamField body="customerInfo.mobile" type="string" required>
  Mobile phone number of the customer.
</ParamField>

## Response

Successful Response

<Note>
  The `data` object fields shown below are representative. They identify the newly
  registered customer and the product they were registered on.
</Note>

### Main Structure (Root)

<ResponseField name="statusCode" type="integer">
  Status code from API.
</ResponseField>

<ResponseField name="message" type="string">
  Status message that describes the status code (`"success"` on success).
</ResponseField>

<ResponseField name="data" type="object">
  Object containing details of the registered customer.
</ResponseField>

### data Structure (Object)

<ResponseField name="customerId" type="string">
  Unique identifier of the newly registered customer record.
</ResponseField>

<ResponseField name="paymentLinkId" type="string">
  Unique identifier of the credit usage product (the `productId`) the customer was
  registered on.
</ResponseField>

### Errors

<ResponseField name="400 Not Authorized" type="object">
  Returned when the authenticated user does not own the product:
  `{ "statusCode": 400, "message": "You are not authorized to edit this product!" }`.
</ResponseField>

<ResponseField name="400 Email Already Registered" type="object">
  Returned when the email is already registered on the product:
  `{ "statusCode": 400, "message": "Email sudah terdaftar pada product ini." }`.
</ResponseField>

<ResponseField name="400 Validation Error" type="object">
  Returned when a required body parameter is missing or invalid. Validation errors

  `{ "statusCode": 400, "messages": "Validation Error", "data": [ ... ] }`.
</ResponseField>

<ResponseField name="500 Internal Server Error" type="object">
