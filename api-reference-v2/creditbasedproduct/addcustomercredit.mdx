## Request Body

<ParamField body="customerId" type="string" required>
  The unique identifier of the customer whose credit will be increased.
</ParamField>

<ParamField body="productId" type="string" required>
  The unique identifier of the product associated with the credit.
</ParamField>

<ParamField body="amount" type="integer" required>
  The amount of credit to add (positive integer).
</ParamField>

## Response

Successful Response

### Main Structure (Root)

<ResponseField name="statusCode" type="integer">
  Status code from API.
</ResponseField>

<ResponseField name="message" type="string">
  Status message that describes the status code (`"success"` on success).
</ResponseField>

<ResponseField name="data" type="object">
  Object containing details of the credit that was added.
</ResponseField>

### data Structure (Object)

<ResponseField name="customerId" type="string">
  Unique identifier of the customer that received the credit.
</ResponseField>

<ResponseField name="productId" type="string">
  Unique identifier of the product associated with the credit.
</ResponseField>

<ResponseField name="membershipTierId" type="string | null">
  Membership tier identifier. Always `null` for a credit based product.
</ResponseField>

<ResponseField name="amount" type="integer">
  The amount of credit that was added.
</ResponseField>

<ResponseField name="customerBalance" type="float">
  The customer's total credit balance after the credit was added.
</ResponseField>

<ResponseField name="500 Internal Server Error" type="object">
