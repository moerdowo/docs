{/*
  Notes for maintainers — V2 Webhook "Retry History" (POST /hl/v2/webhooks/retry).
  Re-queues a webhook delivery to the merchant's registered webhook URL. The delivery to re-send is
  reconstructed from the request body (paymentLinkId, type, payload, paymentLinkTransactionId) — the
  handler does NOT look up a stored history row by id, so there is NO `webhookHistoryId` field and NO
  "history not found" 404. It only guards that a webhook URL is already registered (400 otherwise).
  Success body is exactly {statusCode:200, messages:"success"} with NO data key. Source-confirmed;
  not captured live (it triggers a real re-delivery). Envelope is PLURAL `messages` (writes and errors).
*/}

## Authorization

  `Authorization | Bearer Paste-Your-API-Key-Here`

## Request Body

The fields below describe the webhook delivery to re-send — typically copied from a webhook
history record (see **Get History**). The webhook is delivered to the URL you registered with
**Register URL Hook**; no destination URL is read from the request body.

<ParamField body="paymentLinkId" type="string">
  ID of the payment link / product the delivery relates to.
</ParamField>

<ParamField body="paymentLinkTransactionId" type="string">
  ID of the transaction the delivery relates to.
</ParamField>

<ParamField body="type" type="string">
  Webhook event type to re-send (example: `"payment.received"`).
</ParamField>

<ParamField body="payload" type="string">
  Webhook payload to re-send, as a JSON-encoded string.
</ParamField>

## Response

Successful Response

### Main Structure (Root)

<ResponseField name="statusCode" type="integer" >
  Status code form API.
</ResponseField>

<ResponseField name="messages" type="string" >
  Status message that describes the status code.
</ResponseField>

## Errors

<ResponseField name="400 — no registered URL hook" type="object">
  Returned when no webhook URL is registered yet: `{ "statusCode": 400, "messages": "Url tidak ditemukan. Silahkan register url webhook anda terlebih dahulu." }`. Register a webhook URL first before retrying a delivery.
</ResponseField>
