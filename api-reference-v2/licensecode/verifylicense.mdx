<Note>
  Software license verification runs on a dedicated service at `/software/v1`, so
  the base URL is `https://api.mayar.id/software/v1` (sandbox
  `https://api.mayar.club/software/v1`) — separate from the shared gateway base
  used by most endpoints. This service returns `isLicenseActive` plus a `licenseCode` object
  instead of the `{ statusCode, messages, data }` envelope, and its errors use the
  singular `message` key.
</Note>

## Authorization

<ResponseField name="Authorization" type="string" required>
  Example:

  `Authorization | Bearer Paste-Your-API-Key-Here`
</ResponseField>

## Request Body

<ParamField body="licenseCode" type="string" required>
  The license code to verify.
</ParamField>

<ParamField body="productId" type="string" required>
  The ID of the product (payment link) associated with the license.
</ParamField>

## Response

Successful Response

### Main Structure (Root)

<ResponseField name="statusCode" type="integer" >
  Status code from API.
</ResponseField>

<ResponseField name="isLicenseActive" type="boolean" >
  Shows whether the license is currently active (`true` when `status` is `ACTIVE`).
</ResponseField>

<ResponseField name="licenseCode" type="object">
  Detailed information about the license code.
</ResponseField>

### licenseCode Structure (Object)

<ResponseField name="licenseCode" type="string" >
  The license code value.
</ResponseField>

<ResponseField name="status" type="string" >
  License status. One of `ACTIVE`, `INACTIVE`, `EXPIRED`, or `DISABLED`.
</ResponseField>

<ResponseField name="expiredAt" type="string" >
  License expiration date as an ISO 8601 datetime, or `"Tidak terbatas"`
  (Unlimited) when there is no expiry.
</ResponseField>

<ResponseField name="transactionId" type="string<uuid>" >
  Related transaction ID.
</ResponseField>

<ResponseField name="productId" type="string<uuid>" >
  ID of the associated product.
</ResponseField>

<ResponseField name="customerId" type="string<uuid>" >
  Customer ID linked to the license.
</ResponseField>

<ResponseField name="customerName" type="string" >
  Customer's full name.
</ResponseField>

<ResponseField name="customerEmail" type="string" >
  Customer's email address.
</ResponseField>

<ResponseField name="activationLimit" type="string" >
  Maximum number of allowed activations (example: `"Tidak terbatas"` → Unlimited).
</ResponseField>

<ResponseField name="useCount" type="number" >
  Number of times the license has been used. Incremented on each successful
  verification of an `ACTIVE` license; when it reaches the activation limit the
  license becomes `INACTIVE`.
</ResponseField>

<ResponseField name="createdAt" type="string" >
  License creation timestamp (ISO 8601 datetime).
</ResponseField>

<ResponseField name="updatedAt" type="string" >
  Last updated timestamp (ISO 8601 datetime).
</ResponseField>

### Errors

<ResponseField name="400 Bad Request" type="object">
  Returned when `licenseCode`/`productId` are missing, or when no matching license
  is found for the authenticated user:
  `{ "statusCode": 400, "message": "There's no license with code <code> and product id <id> registered in user <email>." }`.
  Note the singular `message` key used by this service.
</ResponseField>
