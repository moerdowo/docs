<Note>
  Product search in V2 is a query on the products list endpoint: pass the `search`
  keyword to `GET /hl/v2/products`. There is no dedicated `/products/search` path.
  The `search` parameter can be combined with `type`, `stock`, `limit`, and
  `startingAfter`.
</Note>

## Query Parameters

<ParamField query="search" path="search" type="string">
  Keyword to filter products by name. Matching is case-insensitive.
</ParamField>

<ParamField query="type" path="type" type="string">
  Optionally narrow the search to a product type (e.g. `generic_link`, `event`,
  `webinar`, `digital_product`).
</ParamField>

<ParamField query="stock" path="stock" type="string">
  Optionally filter by stock availability.
</ParamField>

<ParamField query="limit" path="limit" default="10" type="integer">
  Number of items to return per page. Defaults to `10`, with a maximum of `50`.
</ParamField>

<ParamField query="startingAfter" path="startingAfter" type="string">
  Cursor for forward pagination. Pass the `nextStartingAfter` value from the
  previous response (a Unix timestamp in milliseconds, as a string) to fetch the
  next page.
</ParamField>
