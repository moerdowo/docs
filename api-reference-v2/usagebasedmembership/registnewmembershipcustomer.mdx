## Authorization

  `Authorization | Bearer Paste-Your-API-Key-Here`

## Request Body

<ParamField body="productId" type="string" required>
  The unique identifier of the product associated with the credit.
</ParamField>

<ParamField body="membershipTierId" type="string" required>
  The unique identifier of the membership tier to assign to the customer.
</ParamField>

<ParamField body="customerInfo" type="object" required>
  Object containing the customer's details.
</ParamField>

<ParamField body="trialCredit" type="number">
  The trial credit amount to grant upon registration.
</ParamField>

<ParamField body="membershipMonthlyPeriod" type="number">
  The membership period in months. Must be one of `1`, `3`, `6`, or `12`.
</ParamField>

### customerInfo Structure (Object)

<ParamField body="name" type="string" required>
  Full name of the customer.
</ParamField>

<ParamField body="email" type="string" required>
  Email address of the customer.
</ParamField>

<ParamField body="mobile" type="string" required>
  Mobile phone number of the customer.
</ParamField>

## Response

Successful Response

### Main Structure (Root)

<ResponseField name="statusCode" type="integer">
  Status code from API.
</ResponseField>

<ResponseField name="message" type="string">
  Status message that describes the status code (`"success"` on success).
</ResponseField>

<ResponseField name="data" type="object">
  Object containing the registered membership customer and their payment link.
</ResponseField>

### data Structure (Object)

<ResponseField name="membershipCustomer" type="object">
  The newly registered membership customer record.
</ResponseField>

<ResponseField name="paymentLinkUrl" type="string">
  URL the customer can use to pay for the membership.
</ResponseField>

### membershipCustomer Structure (Object)

<ResponseField name="id" type="string">
  Unique identifier of the membership customer record.
</ResponseField>

<ResponseField name="memberId" type="string">
  The member identifier assigned to the customer.
</ResponseField>

<ResponseField name="customerId" type="string">
  The unique identifier of the customer.
</ResponseField>

<ResponseField name="paymentLinkId" type="string">
  Unique identifier of the payment link associated with this membership.
</ResponseField>

<ResponseField name="membershipTierId" type="string">
  The unique identifier of the membership tier assigned to the customer.
</ResponseField>

<ResponseField name="status" type="string">
  Current membership status (e.g., `active`).
</ResponseField>

<ResponseField name="monthlyPaymentPeriod" type="number">
  The membership billing period in months.
</ResponseField>

<ResponseField name="isInTrial" type="boolean">
  Indicates whether the membership is currently in its trial period.
</ResponseField>

<Info>
  `membershipCustomer` is the full member record; additional fields may be present.
  The set above is representative.
</Info>

### Errors

<ResponseField name="400 Not Authorized" type="object">
  Returned when the authenticated user does not own the product:
  `{ "statusCode": 400, "message": "You are not authorized to edit this product!" }`.
</ResponseField>

<ResponseField name="400 Email Already Registered" type="object">
  Returned when the email is already registered on the tier:
  `{ "statusCode": 400, "message": "Email sudah terdaftar pada tier ini." }`.
</ResponseField>

<ResponseField name="400 Validation Error" type="object">
  Returned when required fields are missing or invalid. Validation errors use the
  PLURAL `messages` key with a `data` array of field errors:
  `{ "statusCode": 400, "messages": "Validation Error", "data": [ ... ] }`.
</ResponseField>
