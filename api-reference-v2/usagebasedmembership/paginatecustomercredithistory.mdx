## Path Parameters

<ParamField path="customerId" type="string" required>
  The unique identifier of the customer whose credit history is being queried.
</ParamField>

## Query Parameters

<ParamField query="productId" type="string">
  The unique identifier of the product associated with the credit history.
</ParamField>

<ParamField query="membershipTierId" type="string">
  The unique identifier of the membership tier associated with the credit history.
</ParamField>

<ParamField query="page" default="1" type="integer">
  The page number for pagination.
</ParamField>

<ParamField query="limit" default="10" type="integer">
  The number of items to return per page.
</ParamField>

<ParamField query="sortField" default="datetime" type="string">
  The field name used to sort results.
</ParamField>

<ParamField query="sortOrder" default="desc" type="string">
  The order of sorting. Accepts `"asc"` or `"desc"`.
</ParamField>

<ParamField query="startDate" type="string">
  The start date filter for the query range.
</ParamField>

<ParamField query="endDate" type="string">
  The end date filter for the query range.
</ParamField>

<ParamField query="walletType" type="string">
  The type of wallet to filter credit history (e.g., `"MEMBERSHIP"`, `"ADD_ON"`).
</ParamField>

<ParamField query="type" type="string">
  The transaction type filter (e.g., `"TOPUP"`, `"MERCHANT_TOPUP"`, `"TRIAL_TOPUP"`, `"EXPIRE_VOID"`, `"CREDIT_USAGE"`).
</ParamField>

## Response

Successful Response

### Main Structure (Root)

<ResponseField name="statusCode" type="integer">
  Status code from API.
</ResponseField>

<ResponseField name="message" type="string">
  Status message that describes the status code (`"success"` on success).
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of records matching the query.
</ResponseField>

<ResponseField name="page" type="integer">
  The current page number.
</ResponseField>

<ResponseField name="limit" type="integer">
  The current page size (items per page).
</ResponseField>

<ResponseField name="totalPages" type="integer">
  The total number of pages available.
</ResponseField>

<ResponseField name="data" type="array of object">
  List of credit history records for the requested page.
</ResponseField>

### data Structure (Array Of Object)

Each history item carries the ledger `credit`/`debit` amounts plus metadata.

<ResponseField name="id" type="string">
  Unique identifier of the credit history record.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp of the record as an ISO 8601 datetime.
</ResponseField>

<ResponseField name="credit" type="number">
  Amount credited to the customer's balance in this entry.
</ResponseField>

<ResponseField name="debit" type="number">
  Amount debited from the customer's balance in this entry.
</ResponseField>

<ResponseField name="productId" type="string">
  The unique identifier of the product associated with the entry.
</ResponseField>

<ResponseField name="status" type="string">
  Status of the entry (e.g., `ACTIVE`).
</ResponseField>

<ResponseField name="membershipTierId" type="string">
  The unique identifier of the membership tier associated with the entry.
</ResponseField>

<ResponseField name="customerId" type="string">
  The unique identifier of the customer associated with the entry.
</ResponseField>

<ResponseField name="merchantId" type="string">
  The unique identifier of the merchant associated with the entry.
</ResponseField>

<ResponseField name="walletType" type="string">
  The wallet type of the entry (e.g., `MEMBERSHIP`, `ADD_ON`).
</ResponseField>

<ResponseField name="type" type="string">
  The transaction type of the entry (e.g., `TOPUP`, `EXPIRE_VOID`, `CREDIT_USAGE`).
</ResponseField>

<ResponseField name="referenceId" type="string">
  Reference identifier linking the entry to a related transaction.
</ResponseField>
