## Authorization

<ResponseField name="Authorization" type="string" required>
  Example:

  `Authorization | Bearer Paste-Your-API-Key-Here`
</ResponseField>

## Query Parameters

<ParamField query="productId" type="string" required>
  The unique identifier of the product associated with the credit balance.
</ParamField>

<ParamField query="membershipTierId" type="string" required>
  The unique identifier of the membership tier associated with the credit balance.
</ParamField>

<ParamField query="memberId" type="string">
  The unique identifier of the member whose credit balance is being queried.
</ParamField>

<ParamField query="customerId" type="string">
  The unique identifier of the customer whose credit balance is being queried.
</ParamField>

<Note>
  At least **one of** `memberId` **or** `customerId` must be provided.
</Note>

## Response

Successful Response

### Main Structure (Root)

<ResponseField name="statusCode" type="integer">
  Status code from API.
</ResponseField>

<ResponseField name="message" type="string">
  Status message that describes the status code (`"success"` on success).
</ResponseField>

<ResponseField name="data" type="object">
  Object containing the customer balance and membership-customer details.
</ResponseField>

### data Structure (Object)

<ResponseField name="customerBalance" type="float">
  Total credit balance (membership plus add-on).
</ResponseField>

<ResponseField name="customerBalanceMembership" type="float">
  Credit balance with `MEMBERSHIP` type.
</ResponseField>

<ResponseField name="customerBalanceAddon" type="float">
  Credit balance with `ADD_ON` type.
</ResponseField>

<ResponseField name="customerEmail" type="string">
  Email address of the customer.
</ResponseField>

<ResponseField name="customerName" type="string">
  Full name of the customer.
</ResponseField>

<ResponseField name="customerMobile" type="string">
  Mobile phone number of the customer.
</ResponseField>

<ResponseField name="status" type="string">
  Current membership status (e.g., `active`).
</ResponseField>

<ResponseField name="nextPayment" type="string">
  Next scheduled payment date as an ISO 8601 datetime.
</ResponseField>

<ResponseField name="expiredAt" type="string">
  Membership expiration date as an ISO 8601 datetime.
</ResponseField>

<Info>
  Additional membership-customer fields may be present in `data` (the response
  spreads the member record). The set above is representative.
</Info>

### Errors

<ResponseField name="400 Bad Request" type="object">
  Returned when required parameters are missing or invalid. Validation errors use
  the PLURAL `messages` key with a `data` array of field errors:
  `{ "statusCode": 400, "messages": "Validation Error", "data": [ ... ] }`.
</ResponseField>
