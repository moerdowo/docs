<Note>
  The invoice to update is selected by the `{uuId}` segment in the URL path. The
  handler uses it for both the existence check (`404 Invoice not found`) and the
  ownership check (`401 Unauthorized`), and echoes it back as `data.id`. Do not send
  an `id` in the request body — the invoice-edit body carries only the fields to
  change.
</Note>

## Authorization

<ResponseField name="Authorization" type="string" required>
  Example:

  `Authorization | Bearer Paste-Your-API-Key-Here`
</ResponseField>

## Path Parameters

<ParamField path="uuId" type="string<uuid>" required>
  Unique identifier of the invoice to update, obtained when the invoice was created.

  Example:

  `6f8c19ff-5b97-4792-aa89-d2a12797b356`
</ParamField>

## Request Body

<ParamField path="items" type="array" required>
  List of invoice line items. The invoice `amount` and `subtotal` are recomputed
  from these items.
</ParamField>

<ParamField path="items[].quantity" type="number" required>
  Quantity of the item.
</ParamField>

<ParamField path="items[].rate" type="number" required>
  Price per item.
</ParamField>

<ParamField path="items[].description" type="string" required>
  Description of the item.
</ParamField>

<ParamField path="description" type="string">
  Description or notes related to the invoice (5–555 characters).
</ParamField>

<ParamField path="expiredAt" type="string">
  Invoice expiration time as a 24-character ISO 8601 UTC string (e.g.
  `2026-07-19T16:43:23.000Z`).
</ParamField>

<ParamField path="redirectUrl" type="string">
  URL the customer is redirected to after payment.
</ParamField>

<ParamField path="notes" type="string">
  Additional notes for the invoice (max 24 characters).
</ParamField>

<ParamField path="tax" type="integer">
  Tax percentage applied to the invoice subtotal.
</ParamField>

<ParamField path="paymentMethod" type="string">
  Restrict the invoice to a specific payment method. When set, the response `data`
  includes a `paymentDetail` object.
</ParamField>

<ParamField path="cashtag" type="string">
  Cashtag used when `paymentMethod` targets the JeniusPay e-wallet channel.
</ParamField>

<ParamField path="extraData" type="object">
  Additional custom key/value data to merge into the invoice transaction. Sending an
  empty string value for a key removes that key.
</ParamField>

## Response

Successful Response

### Main Structure (Root)

<ResponseField name="statusCode" type="integer" >
  Status code form API.
</ResponseField>

<ResponseField name="messages" type="string" >
  Status message that describes the status code.
</ResponseField>

<ResponseField name="data" type="object">
  The updated invoice data.
</ResponseField>

### data Structure (Object)

<ResponseField name="id" type="string<uuid>" >
  Unique invoice ID (echoed from the `{uuId}` path segment).
</ResponseField>

<ResponseField name="transactionId" type="string<uuid>" >
  Identifier of the invoice's associated transaction.
</ResponseField>

<ResponseField name="link" type="string" >
  The URL that customers can access to open the invoice.
</ResponseField>

<ResponseField name="amount" type="number" >
  Total invoice amount recomputed from the items (subtotal plus tax).
</ResponseField>

<ResponseField name="items" type="array of object" >
  The updated line items (`quantity`, `rate`, `description`).
</ResponseField>

<ResponseField name="description" type="string" >
  Updated invoice description.
</ResponseField>

<ResponseField name="status" type="string" >
  Current invoice status (e.g. `unpaid`).
</ResponseField>

<ResponseField name="subtotal" type="number" >
  Sum of `rate × quantity` across all items, before tax.
</ResponseField>

<ResponseField name="expiredAt" type="string | null" >
  Invoice expiry as an ISO 8601 UTC string, or `null` when the invoice does not expire.
</ResponseField>

<ResponseField name="updatedAt" type="string" >
  Time the invoice was updated, as an ISO 8601 UTC string.
</ResponseField>

<ResponseField name="extraData" type="object" >
  Merged custom data, present only when `extraData` was supplied.
</ResponseField>

<ResponseField name="paymentDetail" type="object" >
  Payment-channel details, present only when the request supplied a `paymentMethod`.
</ResponseField>

### Errors

<ResponseField name="400 Bad Request" type="object">
  Returned when the request body fails validation:
  `{ "statusCode": 400, "messages": "Validation Error" }` or
  `{ "statusCode": 400, "messages": "extraData Validation Error" }`.
</ResponseField>

<ResponseField name="401 Unauthorized" type="object">
  Returned when the API key is missing/invalid or the invoice belongs to another
  merchant: `{ "statusCode": 401, "messages": "Unauthorized" }`.
</ResponseField>

<ResponseField name="404 Not Found" type="object">
  Returned when no invoice matches the `{uuId}` path segment:
  `{ "statusCode": 404, "messages": "Invoice not found" }`.
</ResponseField>

<ResponseField name="409 Conflict" type="object">
  Returned when the invoice has already been paid and can no longer be edited:
  `{ "statusCode": 409, "messages": "Transaction already paid. Cannot edit invoice." }`.
</ResponseField>
